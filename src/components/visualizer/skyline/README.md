# 天际（Skyline）

车载天际屏风格的歌词：中间一行逐字填色的当前句，两侧是随换句推进的 3D 词云，演唱位置上方有一串闪烁的粒子尾迹。默认纯黑底（`entry.tsx` 的 `background: false`），可切换为跟随 Folia 的主题色。

## 文件

| 文件 | 作用 |
| --- | --- |
| `entry.tsx` | 注册样式、命令、图标、设置面板、快捷开关 |
| `tuning.ts` / `types.ts` | 参数、默认值、取值范围（存储读取、模组可写范围、面板滑块共用 `SKYLINE_RANGES`） |
| `VisualizerSkyline.tsx` | React 外壳：挂载引擎，自己的 RAF 读 `currentTime` 驱动；逐帧数据不进 React state |
| `skylineEngine.ts` | 不依赖 React 的引擎：组装下面三层，布局、配色过渡、简单的低频起音检测 |
| `centerLyrics.ts` | 中间主歌词（DOM）：换句过渡、句内放大、连续填色边缘、上浮、长音强调、间奏圆点 |
| `wordTunnel.ts` | 两侧词云的运动模型："按句推进的镜头"，画面只由时间决定 |
| `canvas2DWordField.ts` / `spriteCache.ts` / `words.ts` | 词云的 Canvas 2D 渲染、预生成的模糊文字贴图、从歌词里挑词（`Intl.Segmenter` 分词） |
| `sparks.ts` | 粒子尾迹，画在词云同一块画布上 |
| `easing.ts` / `timedAnim.ts` | 换句曲线（主歌词 CSS 与词云 JS 共用一条）、句内放大用的时间同步 Web Animation |
| `skylineLyrics.ts` | Folia `Line[]` → 引擎用的歌词结构 |
| `skyline.css` | 全部规则限定在 `.sk-root` 下 |

## 运动规律（来自对原视频的逐帧实测）

- **每一轮前进一步**：约一半在句内按"这句唱到哪了"匀速前进，另一半在换句时推进（`driftShare = 0.5`）。两部分首尾相接，没有停顿。
- **换句曲线**：静止起步、约 0.14 秒加速到最快、柔和停住，时长 0.75 秒（`easing = 'smooth'`，即 `cubic-bezier(0.3, 0, 0, 1)`）。主歌词换句与词云推进同时开始、用同一条曲线。
- **主歌词句内放大**：按演唱进度匀速放大，整句约 1.35 倍（`grow = 1.35`，从 1/√r 到 √r）。原视频几句实测 1.34～1.43 倍，与句长无关。
- **两侧的词不接律动**：接鼓点会在两句之间"心跳"式跳动，原视频里是平稳的。律动只作用于粒子数量和光晕。

## 性能要点

- 瓶颈在 GPU 合成（高分屏、高刷新率）。不要给大量小元素加合成器动画或独立图层；只有"句内放大"整行用一个 Web Animation（按动画最大尺寸栅格化，放大时文字不糊）。
- 其余逐帧更新直接写 `transform`，不用会被子元素继承的 CSS 自定义变量。
- 词云贴图在空闲时提前生成（每帧最多约 1.2ms），模糊档位用半分辨率，并在相邻档位间交叉淡化；只清除、着色画过的区域。
- 先读布局（演唱位置）再写样式，避免强制同步重排。
